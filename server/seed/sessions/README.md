# Session files for the demo class

Each JSON file is one session, loaded by `npm run seed` under a fictional classmate's name (and reused under the classmates in `alsoAs`). Never write or edit these by hand.

- `sim-*.json`: **simulated demo students** (`"simulated": true`, with a `persona`), generated by `npm run demo:generate`. An AI plays the student (their code, drafts and viva answers); the real platform asked the viva questions, scored them, ran the hidden tests and raised the flags. Demo data, never a measured result.
- Other files: real sessions recorded by people, saved with `npm run session:export` (see docs/recording-guide.md).

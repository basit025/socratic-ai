# Prototype (reference only)

This folder is the team's first Socratic AI prototype, **exported unchanged from Google AI Studio on Nov 22, 2026** (inside the hackathon build window, Nov 16–28). It was generated with AI Studio's coding assistant, which is disclosed in the main README.

It is kept here so the commit history shows exactly what existed before the main build started. It is **not built or deployed**: the platform lives in `client/`, `server/`, `shared/` and `api/`. Ideas carried over (and rewritten) from it: the Ustaad mentor prompt and its JSON response shape, the run-first / explain-first workflows, Pyodide code execution, and the Pakistani-context assignments.

Left out of the import: `.env.example` (placeholder key names only) and `bun.lock` (a generated lockfile).
